# Lunari Jewellery

**Front-end e-commerce site for a premium jewellery brand. Built with HTML, CSS and JavaScript. Live on GitHub Pages.**

**Live site:** [emirdemirkol.github.io/lunari](https://emirdemirkol.github.io/lunari/)

## At a glance

- 12-page storefront covering the full customer journey: browse, cart, checkout, account
- 16-product catalogue with pricing, merchandising badges and Add to Cart
- Responsive layout across desktop, tablet and mobile
- Consistent premium brand identity across every page
- Group project, DCU web design module

## What I built

| Area | My work |
| --- | --- |
| Products page | Responsive product grid, 16 product cards, pricing, badges, Add to Cart |
| Cart | Cart summary with subtotal, shipping and total, link to checkout |
| Checkout | Checkout page prototype |
| About | Editorial brand page with hero banner and alternating image and text sections |
| Contact | Contact page |
| Brand and product direction | Product concepts, naming, pricing and the visual direction for the product imagery |

## Tech stack

```text
HTML5         page structure and content
CSS3          custom stylesheet, responsive grid, brand styling
JavaScript    cart logic and page interaction
GitHub Pages  hosting and deployment
```

## Scope

Front-end prototype. Login, cart and checkout are not connected to a backend or payment provider. All products and brand content are fictional.
